## 2. 추천 아이디어

### A. "받아주는 응급실" 가족 응급 내비 (이슈 ①, 펫밀리 확장 가능)
**한 줄**: 가족이 갑자기 아플 때, **지금 병상이 있는 응급실** 중 실제 도로 기준으로 가장 빨리 도착하는 곳을 골라 바로 출발한다.

| 항목 | 내용 |
|---|---|
| 동작 | ① 응급 버튼 → **"생명이 위급하면 119 먼저"** 안내(자가 이송은 경증·중등증, 소아 고열 등) ② 실시간 응급실 병상 API로 후보 필터 ③ 후보마다 `requestTrip` → 실제 ETA·도착 SOC 비교 (0.2초, 화면 전환 없음 [실측]) ④ `requestRoute`로 즉시 안내 ⑤ 가족에게 도착 예정 공유 |
| 차량특화 | 폰 앱은 병상 "목록"을 보여줄 뿐, **이 차의 현재 위치·배터리로 실제 도착 시간을 비교해 원터치로 경로를 거는 것**은 차량+내비 결합만 가능 |
| 데이터 | 행정안전부 "의료기관 실시간 병상정보"(국립중앙의료원 연계, 실시간, JSON) [출처 4], 국립중앙의료원 응급의료정보 API [출처 5] — **엔드포인트·필드 상세는 미확인** |
| 확장 | 야간 소아(달빛어린이병원 — 운영 정보는 있으나 공개 API는 이번 검색에서 미확인 [출처 20]), 반려동물(24시 동물병원 데이터 미확인) |
| 리스크 | 의료 판단으로 오해되지 않게(119 우선, "병상 정보 기반 안내"로 한정), 병상 정보 지연·정확도, 응급실 도착 후 수용은 보장 못함 |
| 시연 | 정차 중 완결 (병상 API 실데이터 + `requestTrip` 실측) |

### B. EV 지하주차장 안심 인증 (이슈 ②)
**한 줄**: 아파트 지하주차장에 들어갈 때 차가 **충전율을 자동으로 인증**하고, 단지 단위로 익명화한 "EV 안심 현황"을 보여줘 입주민 간 불신을 데이터로 해소한다.

| 항목 | 내용 |
|---|---|
| 동작 | ① 단지 위치 도착 감지(현재 위치) ② SOC 읽기 [실측] → 90% 이하면 "지하 진입 OK" 인증, 초과면 "지상 주차·충전 상한 낮추기" 안내 ③ 주차(P) 후 화면에 인증 결과, 관리사무소·입주민 앱에는 익명 집계(예: "이번 주 EV 지하 진입 312회, 전부 90% 이하") ④ EV 시스템·저전압 경고등이 켜진 상태면 지하 진입 자제 안내(PRIVATE 퍼미션 승인 시) |
| 차량특화 | 충전율을 **차가 직접 증명** → 자기 신고·주차장 카메라로는 불가능. 현대차그룹 입장에서도 EV 불안 해소는 전략 과제 |
| 데이터 | SOC [실측], 위치 [실측], 경고등(PRIVATE, 선택) |
| 리스크 | 서울시 권고는 강제력 없음 → 단지 도입 의지에 의존(B2B: 아파트 관리 플랫폼 제휴), 충전율과 화재의 인과는 논쟁 중(서울시도 노후·결함 화재 가능성 인정) [출처 7], 진입 순간(D)에는 화면 표시 불가 → 인증은 백그라운드·서버, 표시는 P에서, 위치·충전 정보의 개인정보 동의 |
| 시연 | 콘솔 SOC 92% → 단지 도착(P) → "지하 진입 전 충전율 초과" / SOC 85% → 인증 완료 + 현황판 |

### C. 펫밀리 모드를 사회 이슈와 연결 (이슈 ④ + ③)
- **휴가철 유기·차내 방치**: 롤콜·리드줄 하차 가드·마지막 하차 지점·차내 대기 판단([idea-petmily.md](idea-petmily.md)) + 반려동물 동반여행 API로 "데려갈 수 있는 곳" 제시.
- **졸음운전**: 반려견 2시간 휴식 권장(농식품부) + 운전자 휴식을 한 계획으로 → 펫밀리 휴식 리듬 플래너에 "졸음 예방" 근거를 붙일 수 있음.
- A(응급 내비)를 펫밀리의 비상 기능으로 넣으면 **"가족·반려동물 안전 이동"**이라는 하나의 사회적 메시지가 된다.

## 3. 결론
- **사회적 심각성은 ① 응급실 뺑뺑이가 가장 크고, 해결에 필요한 실시간 병상 데이터가 공공 API로 존재한다.** 우리가 실측한 `requestTrip`(여러 병원 실제 ETA를 화면 전환 없이 비교)이 핵심 기술이 되어 기술 활용 설명도 강하다.
- **차량특화성은 ② EV 지하주차장 안심 인증이 가장 크다.** 차만 증명할 수 있는 데이터(SOC)로 사회 갈등을 푸는 구조이고, EV 불안 해소는 주최사 입장에서도 의미가 크다.
- 사용자가 선호한 **펫밀리**는 ④(유기·차내 방치)와 ③(졸음)에 근거를 붙일 수 있고, A를 비상 기능으로 넣으면 사회 문제 연결이 가장 자연스럽다.
- 다음 확인: 응급실 병상 API의 실제 필드(병상 종류·갱신 주기·좌표), 반려동물 동반여행 API 필드, 달빛어린이병원·24시 동물병원 데이터 유무.

### D. 2차 사고 대피 가이드 + 펫밀리 인원 확인 (이슈 ⑨) — 신규 추천
**한 줄**: 고속도로에서 사고·고장으로 서면, **정차 순간** 대피 행동을 단계별로 안내하고, **탑승 명단과 좌석 센서로 아이·반려동물까지 모두 차 밖으로 나갔는지 확인**한다.
