# 시연 영상 · PT 시나리오 (Virtual Console)

> 목표: 2~3분 안에 "차를 바꿨더니 주유구를 못 연다 → 필요한 상황 코스를 고른다 → 직접 조작 → 차가 실제로 바뀐 것을 앱이 확인"을 보여준다.
> 실측(2026-10-27, debug/release APK): 오프닝 ~10초, 단계당 ~10초(음성 포함), 주유·충전 코스 약 25초, 기본 조작 11단계 완주 2분 10초(D/P 일시정지 포함, 코스 분리 전 기준).
> 콘솔 자동 조작: [tools/vc-demo.js](../tools/vc-demo.js) (`__demo.reset()` → `__demo.door()` → `__demo.fuel()` / `basic()` / `weather()` / `climate()` / `family()` / `all()`).

## 준비

1. 에뮬레이터 실행 + `adb forward tcp:8088 tcp:8088` → 브라우저 `http://127.0.0.1:8088/`
2. APK 설치: `adb install -r apk/SYNC_MyCarTutorial_release.apk`
3. 첫 실행 상태로 초기화 (오프닝을 다시 보여주려면): `adb shell pm clear --user 10 com.teamsync.pleos`
4. 브라우저 개발자 도구 콘솔에 `tools/vc-demo.js` 붙여넣기 → `await __demo.reset()`
5. 녹화: 화면 왼쪽 에뮬레이터, 오른쪽 Virtual Console 브라우저를 나란히 두고 **시스템 소리 포함** 녹화 (음성 안내가 핵심). 로그 창(`adb logcat -v time | grep "SYNC/Tutorial"`)을 작게 같이 띄우면 "실제 상태 변화로 판정"이 잘 보인다.

## 말할 포인트 (PT)

- **출발점은 실제 경험** — 차를 바꾸면 주유구·보닛·김서림처럼 "필요한 순간에야 찾는" 기능이 제일 헷갈린다 → 상황별 코스.
- **판정은 화면 버튼이 아니라 Vehicle SDK 콜백의 실제 상태 전이** — 로그 `JUDGE … OFF→ON (live) → 충족`.
- **원래대로 되돌렸는지까지 확인** — 다음 운전에 영향이 남지 않음.
- **차종별 차이를 자동 처리** — 전기차면 주유구 대신 충전구, capability가 없으면 '지원 안 됨' (에뮬레이터: 주유구·주행 모드).
- **Pleos SDK에 없는 신호는 문서 안내대로 AAOS 표준 속성** — 기어(`GEAR_SELECTION`), 주유구·충전구(`FUEL_DOOR_OPEN`·`EV_CHARGE_PORT_OPEN`).
- **정차 중에만 진행** — 기어 P가 아니면 즉시 멈추고 음성으로 알림.
- **음성 안내는 Pleos TextToSpeech 온디바이스** — 네트워크 없이 동작.

## 주의

- 트렁크·보닛은 같은 콘솔 카드(Trunk / Frunk Position)다. 트렁크는 trunk, 보닛은 frunk 선택 (스크립트가 자동 선택).
- 창문 잠금은 콘솔 Window Lock에서 **all**을 골라야 앱이 구독하는 전체 창문 묶음 Area가 바뀐다 (rear_left는 이벤트 없음).
- 에뮬레이터는 실내등을 켜면 뒷좌석 독서등도 같이 켜질 수 있다. 앱은 독서등 단계 시작 시점 값에 맞춰 안내하므로 문제없이 진행된다.
- 오프닝의 운전석 문 트리거는 "홈 화면 + 튜토리얼을 시작한 적 없음 + 직전 재생 후 60초 경과"일 때만 동작.
- 실내등 연출은 `CONTROL_CAR_LIGHTS` 승인 전이라 release에서는 생략된다 (로그 `OPENING lighting skipped`). debug 빌드는 에뮬레이터 검증용으로 선언돼 있다.
