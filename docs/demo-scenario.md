# 시연 영상 · PT 시나리오 (Virtual Console)

> 목표: 2~3분 안에 "처음 타는 차 → 직접 조작 → 차가 실제로 바뀐 것을 앱이 확인"을 보여준다.
> 실측(2026-10-27, release APK): 오프닝 ~10초, 단계당 ~11초, 11단계 완주 2분 10초 (D/P 일시정지 시연 포함).
> 콘솔 자동 조작: [tools/vc-demo.js](../tools/vc-demo.js) (`__demo.reset()` → `__demo.door()` → `__demo.run()`).

## 준비

1. 에뮬레이터 실행 + `adb forward tcp:8088 tcp:8088` → 브라우저 `http://127.0.0.1:8088/`
2. release APK 설치: `adb install -r apk/SYNC_MyCarTutorial_release.apk`
3. 첫 실행 상태로 초기화 (오프닝을 다시 보여주려면): `adb shell pm clear --user 10 com.teamsync.pleos`
4. 브라우저 개발자 도구 콘솔에 `tools/vc-demo.js` 붙여넣기 → `await __demo.reset()`
5. 녹화: 화면 왼쪽 에뮬레이터, 오른쪽 Virtual Console 브라우저를 나란히 두고 화면 녹화 프로그램으로 **시스템 소리 포함** 녹화 (음성 안내가 핵심). 로그 창(`adb logcat -v time | grep "SYNC/Tutorial"`)을 작게 같이 띄우면 "실제 상태 변화로 판정"이 잘 보인다.

## 말할 포인트 (PT)

- **판정은 화면 버튼이 아니라 Vehicle SDK 콜백의 실제 상태 전이** — 로그 `JUDGE … OFF→ON (live) → 충족`.
- **원래대로 되돌렸는지까지 확인** — 다음 운전에 영향이 남지 않음.
- **차종별 지원 차이를 자동 처리** — capability가 없으면 '지원 안 됨'으로 넘어가고 사유를 기록 (에뮬레이터의 주행 모드).
- **정차 중에만 진행** — 기어 P(AAOS `GEAR_SELECTION`)가 아니면 즉시 멈추고 음성으로 알림.
- **음성 안내는 Pleos TextToSpeech 온디바이스** — 네트워크 없이 동작.

## 주의

- 트렁크 카드는 trunk를 선택해야 한다 (기본 frunk). 스크립트는 자동 선택.
- 오프닝의 운전석 문 트리거는 "홈 화면 + 튜토리얼을 시작한 적 없음 + 직전 재생 후 60초 경과"일 때만 동작.
- 실내등 연출은 `CONTROL_CAR_LIGHTS`가 승인되기 전이라 release에서는 생략된다 (로그 `OPENING lighting skipped`). debug 빌드는 에뮬레이터 검증용으로 선언돼 있어 실내등이 4초 켜졌다 원래대로 돌아간다.
