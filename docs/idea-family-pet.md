# 가족 + 반려동물 조합 아이디어 (2026-10-22)

> 질문: 가족 + 애완동물 조합으로 진짜 있으면 좋을 특이한 것.
> **신호**는 실측으로 SDK에서 받는 것만 ([sdk-probe-results.md](sdk-probe-results.md)). **실현성** ◎ 지금 SDK로 핵심 동작 / ○ 외부 데이터·서버 필요 / △ 미검증 센서 의존. **시연** P = 정차 중 완결(에뮬레이터 OK).
> **[미검증]** 데이터 출처 미확인, **[일반 지식]** Pleos에서 확인 안 한 업계 정보.

## 전제: "반려동물이 탔다"는 어떻게 아나
- 반려동물을 구분하는 센서는 없다. 방법은 ① 출발 시 원탭 "오늘 ○○ 탑승" ② 좌석 점유는 켜졌는데 벨트가 안 채워진 좌석(사람은 대개 벨트) → "반려동물인가요?" 한 번 묻고 기억.
- 좌석 점유는 실시간 수신 [실측], 벨트 상태는 Get 가능하지만 Virtual Console로 조작 불가 [실측] → 시연은 ①로.

## 아이디어

### 1. 야간 응급 이동 버튼 (아이 / 반려동물)
**한 줄**: 밤에 아이가 열이 나거나 반려견이 이상할 때, 버튼 하나로 **지금 열려 있는 소아 진료기관·24시 동물병원 중 실제 도착이 가장 빠른 곳**을 골라 바로 출발한다.

| 항목 | 내용 |
|---|---|
| 실제 불편 | 한밤중에 당황한 상태로 "지금 여는 병원"을 폰으로 검색 → 직선거리로 고르면 실제로는 더 오래 걸리기도 함 |
| 동작 | ① 아이/반려동물 선택 ② 후보 기관 목록(공공 데이터) → 후보마다 `requestTrip`으로 **실제 ETA·도착 SOC**를 화면 전환 없이 계산 ③ 운영 중 + 가장 빠른 곳 → `requestRoute`로 즉시 안내 ④ 왕복 배터리 확인, 병원·가족에게 도착 예정 링크 공유 |
| 신호 | `requestTrip` [실측 0.2초, 화면 전환 없음], `requestRoute` [실측], SOC, 현재 위치 |
| 특이 포인트 | 내비는 "병원"을 찾아줄 뿐, **운영 여부 + 실제 도로 ETA로 비교**해 주지 않음. 아이·반려동물 둘 다 밤 응급이 있는 가정에 한 버튼 |
| 데이터 | 야간 소아 진료기관·응급의료기관 정보, 동물병원 정보(24시 여부) — 공공 데이터 [미검증] |
| 실현성 / 시연 | ○ / P (출발 전 비교 화면) |
| 겹침 | 낮음 |

### 2. 목적지 '반려동물 동반 가능' 자동 확인
**한 줄**: 반려견이 탄 상태로 목적지를 정하면, 그곳이 **동반 가능한지 자동으로 확인**하고 안 되면 근처 동반 가능한 곳으로 바꿀지 묻는다.

| 항목 | 내용 |
|---|---|
| 실제 불편 | 가족 나들이 장소(카페·식당·공원)에 도착해서야 "반려동물 출입 불가"를 알게 됨 → 차에 두고 가거나 다시 이동 |
| 동작 | ① 목적지 설정 이벤트(`onDestinationInfo` 이름·좌표) [실측] ② 반려동물 탑승 상태면 동반 가능 여부 조회 ③ 불가면 근처 동반 가능 대안 2~3곳을 `requestTrip`으로 ETA 비교 → 원탭 변경 |
| 신호 | NaviHelper 목적지 이벤트·`requestTrip`·`requestRoute` [실측], 좌석 점유 |
| 특이 포인트 | 내비는 장소의 **반려동물 정책**을 모름. 목적지를 정하는 순간 차가 먼저 확인 |
| 데이터 | 반려동물 동반 여행·장소 정보 공공 데이터 [미검증] |
| 실현성 / 시연 | ○ / P |
| 겹침 | 낮음 |

### 3. 조수석 에어백 × 아이·반려견 좌석 경고
**한 줄**: 조수석에 아이나 반려견이 탔는데 **조수석 에어백이 켜져 있으면**, 출발 전에 "뒷좌석으로" 경고한다.

| 항목 | 내용 |
|---|---|
| 실제 불편 | 조수석 에어백은 어린이·반려동물에게 위험할 수 있는데 [일반 지식], 급할 때 반려견을 조수석에 태우는 일이 흔함 |
| 동작 | P에서 출발 전: 조수석 점유 + (벨트 미체결 또는 "반려동물/어린이" 지정) + 조수석 에어백 활성 → 큰 경고 |
| 신호 | `hasSeatAirbagEnabled(ROW_1_RIGHT)` [실측 Get 지원], 좌석 점유 [실측], 벨트 상태 [실측 Get] |
| 특이 포인트 | 순정은 조수석 에어백 ON/OFF **표시등**만 있음(텔테일 타입 `PASSENGER_AIRBAG_OFF/ON` 존재) [실측: AAR]. **누가 탔는지와 묶어서 경고**하는 건 없음 |
| 실현성 / 시연 | ◎ / P |
| 겹침 | 중간 (표시등은 순정) |

### 4. "리드줄 먼저" 하차 가드
**한 줄**: 반려견이 탄 채로 P가 되면 **문을 열기 전에** "리드줄을 먼저 잡으세요"를 크게 띄우고, 고속도로 휴게소에서는 더 강하게 알린다.

| 항목 | 내용 |
|---|---|
| 실제 불편 | 휴게소에서 문을 여는 순간 반려견이 뛰쳐나가 실종·사고 [일반 지식] |
| 동작 | Gear P 전환(문 열기보다 먼저 옴) + 반려동물 탑승 → 하차 가드 화면. 뒷문 열림 이벤트로 "확인 완료" 처리, 위치가 휴게소면 강조 |
| 신호 | Gear [실측], 도어 위치(뒷문 1↔0) [실측], 현재 위치 |
| 특이 포인트 | 단순하지만 차가 **하차 직전의 정확한 순간**(P 전환)을 알기 때문에 가능한 알림 |
| 실현성 / 시연 | ◎ / P |
| 겹침 | 낮음 |

### 5. 펫밀리 휴식 리듬 플래너
**한 줄**: 아이(약 90분)와 반려견(약 120분)의 쉬는 주기 중 짧은 쪽에 맞춰, **아이 놀이방·수유실과 반려견 놀이터가 같이 있는 휴게소**를 충전까지 고려해 경유지로 짜 준다.

| 항목 | 내용 |
|---|---|
| 실제 불편 | 아이 화장실, 반려견 배변·산책, EV 충전이 따로따로 → 여러 번 정차. 반려견 놀이터가 있는 휴게소는 일부뿐 [일반 지식] |
| 동작 | 출발 전 `requestTrip`(총 시간·도착 SOC) → 휴식 횟수 결정 → 조건 맞는 휴게소를 경유지로 최대 2개씩 → 휴게소 도착(P) 시 다음 구간 재계획 |
| 신호 | `requestTrip`·`requestRouteWithWaypoints`·`onWayPointArrived`·`onDrivingInfo`(경유지 충전소 여부·충전기 수) [실측], SOC, 좌석 점유 |
| 데이터 | 휴게소 편의시설(놀이방·수유실·반려견 놀이터·충전기) [미검증] |
| 실현성 / 시연 | ○ / P |
| 겹침 | 순정은 배터리 기준 충전 경유만 [실측] |

### 6. 반려견과 차박 — 밤새 적정 온도 + 내일 귀가 계산
**한 줄**: 반려견과 차에서 잘 때, 반려견에게 맞는 온도로 공조를 밤새 켜 두면 **내일 아침 집까지 갈 수 있는지**를 실측 소모율과 실제 경로로 계산한다 (2차 후보 2-C의 반려동물 버전).

| 항목 | 내용 |
|---|---|
| 동작 | P + 공조 ON + 탑승 → 배터리 Wh 소모율 × 남은 시간 → 기상 시 SOC → 집까지 `requestTrip` 도착 SOC → "온도를 1℃ 바꾸면 +n%" 안내(공조 제어는 미오픈 → 안내만) |
| 신호 | 배터리 Wh 주기 콜백·SOC [실측], HVAC 전원·온도 [실측], `requestTrip` [실측] |
| 실현성 / 시연 | ◎ / P |
| 겹침 | 유틸리티 모드·캠프 모드는 공조 유지 기능 [일반 지식] — 귀가 가능 계산은 차별 |

### 7. 잠깐 두고 내릴 때 위험 시계 (참고)
**한 줄**: 반려견을 차에 잠깐 두고 내리면, 날씨·현재 실내 온도·공조 상태로 "공조가 꺼지면 n분 뒤 위험"을 계산해 차 화면과 가족 폰에 표시.
- 테슬라 Dog Mode(공조 유지 + 화면 안내)와 겹침 [일반 지식] → 차별은 **예측 시계 + 가족 공유** 정도. 우선순위 낮음. (○ 서버·날씨 API)
